# PixelMotion Studio

## Implementado

- Preview de espera con skeleton y una barra de actividad indeterminada durante la generación.
- Estado visible mientras Codex trabaja. Codex CLI no entrega un porcentaje de avance, así que la interfaz no inventa uno.
- Pruebas automatizadas para validación y decodificación de frames, selección de timeline, cambio de resolución, estado de espera, integración de generación, proyectos y exportación GIF.

## Cobertura pendiente

- Ampliar pruebas de importación de imágenes, edición manual de píxeles, reproducción, exportación PNG y spritesheet, e impresión cuando esas funciones estén implementadas.
